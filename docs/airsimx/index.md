# AirsimX 开发基线

AirsimX 是基于 Microsoft AirSim 的社区衍生项目，目标是在尽量保持既有接口兼容的前提下，逐步升级 Unreal Engine、飞控支持与无人机算法接入能力。它不是微软官方续作。

> 当前状态：Windows x64 核心构建通过，核心测试在 Release/Debug 下通过（22 项验证）。本文档不代表 UE5、新版飞控或新版 ROS 2 已经受支持。原仓库的发布、构建徽章和使用说明仍属于继承的 AirSim 基线。

## 当前约定

1. 对外项目名使用 **AirsimX**；本阶段不更改远程仓库名称。
2. 暂时保留 UE 模块 `AirSim`、Python 导入名 `airsim`、RPC 接口和现有配置字段，避免无关的兼容性破坏。
3. 先完成单架多旋翼和 SimpleFlight 的 UE5 闭环，再接现代飞控，最后扩展算法生态。
4. “检测到工具”“能编译”和“飞行验证通过”是不同结论，不互相替代。
5. 不将实验性组合标为正式支持；正式支持必须对应精确版本、提交、场景、配置和测试结果。
6. 保留 [MIT 许可证及微软版权声明](../../LICENSE)。Unreal Engine、场景资产及第三方依赖的许可单独遵守，不因本仓库采用 MIT 而自动变成 MIT。

路线图中的候选版本与安装动作尚未执行；修改候选项时，同步更新兼容性矩阵及验证记录。
